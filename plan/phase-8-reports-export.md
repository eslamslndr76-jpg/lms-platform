# المرحلة 8: التقارير والتصدير

المرجع: `edit-plan.md` (الإعدادات والنصوص الافتراضية) + `plan/phase-0-report.md` + `plan/refs/` (نموذج التقرير). تحقق من النقاط 1–4 من المرحلة 0.

## تقرير المجموعة (Word)
**المصدر:** `نموذج_تقرير.docx`.
- زر **"استخراج التقرير"** داخل كل مجموعة، **مُعطَّل قبل الإنهاء** بسبب واضح: "التقرير متاح بعد إنهاء المجموعة".
- يُولَّد من **أحدث البيانات وقت الضغط**؛ لا يُحفظ ملف قديم.
- قسم فارغ أو بلا إجابات استبيان: يُولَّد التقرير والقسم فارغ؛ **لا يُمنع الاستخراج**.

| القسم | المصدر |
|---|---|
| العنوان: اسم الدورة | الكورس |
| مقدم الدورة | محاضر المجموعة |
| منسق الدورة | قيمة ثابتة من الإعدادات |
| الفترة التدريبية (من/إلى) وأيام المحاضرات | جدول المجموعة |

| ‏— الجدول الزمني وميعاد الدورة (من الساعة إلى الساعة) | جدول المجموعة |
| ‏— مقدم الدورة | المحاضر |

| **رابعاً: محاور الدورة** | الكورس (من المحتوى اليومي في المقترح) |
| **خامساً: قائمة المشاركين** (الرقم، اسم الوحدة/الجهة، اسم المشارك) | طلاب المجموعة المسجلون فعلاً |
| **سادساً: نتائج التقييم** | متوسطات الاستبيان (أدناه) |
| **سابعاً: الشهادات** | نص جاهز من الإعدادات؛ لا تغيّر نظام الشهادات |
| **ثامناً: ملاحظات عامة** | مستوى **المجموعة**، نص افتراضي من الإعدادات، قابل للتعديل |
| **تاسعاً: التوصيات** | مستوى **المجموعة**، نص افتراضي من الإعدادات، قابل للتعديل |
| **عاشراً: صور وثائقية** | تُرفع وقت الاستخراج (أدناه) |

**القسم السادس:**
- الأعمدة كما في القالب: مجال التقييم، بند التقييم، متوسط الرضا، متوسط الرضا العام.
- البنود هي **بنود استبيان الطالب (المرحلة 4)** لا البنود الأحد عشر القديمة في القالب، مجمّعة تحت المجالات: **المحاضر، البرنامج، المكان**.
- **مجال المكان يختفي في الأونلاين.**
- يُضاف تحت الجدول: **عدد من أجابوا من إجمالي الطلاب** (مثل "18 من 25"). إضافة مقصودة على القالب.

**بيانات التقرير:** قسم "بيانات التقرير" في صفحة المجموعة (نوع النشاط، الملاحظات، التوصيات) بنصوصها الافتراضية ويعدّل الموظف عند الحاجة.

**الصور:**
- **لا تُخزَّن في النظام ولا في قاعدة البيانات.**
- عند "استخراج التقرير" تظهر نافذة رفع (اختيارية، حتى 8 صور، JPG أو PNG). تُدرج في القسم العاشر بشبكة منظمة بعد تصغيرها ثم تُهمل.
- إعادة الاستخراج تتطلب رفعها من جديد (مقبول). بلا صور: القسم فارغ ويُولَّد التقرير.

## التصدير عموماً
**القاعدة:** أي شيء تطلع عليه الإدارة ورقياً قابل للتصدير. افحص التصدير الموجود وأكمل الناقص **بآلية التصدير الحالية نفسها** دون بناء آلية جديدة.

| ما يُصدَّر | الصيغة |
|---|---|
| تقرير المجموعة | Word |
| مقترح الكورس (بمكان للتوقيع) | Word |
| كشف حضور المجموعة | Excel |
| قائمة المجموعات وطلابها | Excel |
| نتائج الاستبيان | Excel |
| تقييم المحاضر للطلاب (الطالب، درجات الأسئلة الأربعة، المجموع) | Excel |

- **لا تضف PDF جديداً**؛ الموجود أصلاً يبقى كما هو.
- كل الملفات عربي RTL، بأسماء تحتوي اسم الكورس والمجموعة.
- **ملف نتائج الاستبيان:** الردود مع الاسم لمن اختار إظهاره وبدونه لمن لم يختر، مع متوسط كل بند ونسبة من أجابوا.
- تصميم عصري وبسيط والبيانات كاملة.

## معايير القبول
التقرير بكل أقسامه؛ تعطيل الزر قبل الإنهاء؛ اختفاء مجال المكان في الأونلاين؛ تقرير سليم بلا إجابات وبلا صور؛ رفع الصور دون تخزين؛ كل ملفات Excel.
