# المرحلة 3: إنهاء المجموعة

المرجع: `edit-plan.md` + `plan/phase-0-report.md`

**الهدف:** نقطة بداية رسمية لكل ما بعد انتهاء التدريب.

- زر **"إنهاء المجموعة"** يدوي يضغطه الأدمن. **لا إنهاء تلقائي بالتاريخ** (للمرونة في إضافة محاضرة أو تأجيلها).
- الإنهاء **قابل للتراجع**: زر "إعادة فتح المجموعة".
- عند الإنهاء:
  1. يُفتح استبيان الطالب لطلاب المجموعة (المرحلة 4).
  2. يُفتح فورم تقييم الطلاب لمحاضر المجموعة (المرحلة 5).
  3. يصبح زر "استخراج التقرير" متاحاً (المرحلة 8).
  4. تُرسل الإشعارات المقابلة عبر نظام المرحلة 2.
- (هذه المرحلة تضع الحالة والزر والإشعارات؛ الفورمات نفسها تُبنى في المراحل التالية.)

## معايير القبول
الإنهاء وإعادة الفتح؛ ما يتفعّل عند الإنهاء.
