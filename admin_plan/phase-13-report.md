| **حقول الإعدادات** | 50 حقلاً موحّداً على `.md3-field` (بعد إزالة كل الأنماط المضمّنة القديمة): 40px ارتفاع، حدود `outline`، تركيز بلون primary. حقلا اللون `md3-field h-10 p-1`. حقل مدة الحجز `md3-field !w-24`. |
| **الأزرار** | كل أزرار الحفظ/الإضافة/الاختبار → `md3-btn--filled` / `--outlined` / `--text` / `--icon` / `--tonal`. حالات التحميل النصية القائمة بقيت كما هي، والنجاح يظهر في شريط `.msg-ok`. |
| **مفاتيح التبديل** | 3 مفاتيح (الإصدار التلقائي، الحضور مطلوب، تفعيل مزوّد AI) أُعيد بناؤها: مسار 48px داخل زر بمساحة لمس 40px، `role="switch"` + `aria-checked`، اللون من `primary` / `outline-variant`، وموضع المقبض بـ `inset-inline-start` ليعمل صحيحاً في RTL، ولا `opacity` على النص (بطاقة المزوّد المعطّل تُميَّز بحدّ وخلفية `surface-container`). |
| **رفع الشعار** | المعاينة 56px بزوايا M3، زر «اختيار صورة» tonal، وزر الحذف نصي بلون الخطأ. |
| **`/permissions` — التبويبات** | شريط `.md3-tabs` بدل الأزرار الملونة، والوصف (hint) صار سطراً تحت التبويبات بلون `on-surface-variant` بدل نص داخل كل تبويب. |
| **مصفوفة الصلاحيات** | بطاقات الشبكة → **جدول M3 مقروء**: رأس ثابت (`sticky` على `surface-container-high`) داخل حاوية `max-h-[70vh]` مع تمرير أفقي سلس على الموبايل (`min-w-[520px]`)، صفوف بعنوان القسم ووصفه، وخانتا «عرض/تعديل» **checkbox 20px داخل هدف لمس 44px** مع `aria-label` لكل خلية. نفس المكوّن يخدم تبويب الأدوار وتبويب صلاحيات الحساب. |
| **قائمة الأدوار** | الاختيار النشط بـ `bg-primary text-on-primary` وحالة `aria-pressed`، وشارة «نظامي» بلون `primary-container` بدل `rgba(255,255,255,…)`. |
| **جدول بيانات الدخول** | رأس ثابت، صفوف `border-outline-variant`، حشو 12px، والحالة `text-success` / `text-error` (بلا hex). |
| **`/proposals/[id]`** | الأقسام الثلاثة → بطاقات M3، قرار المراجعة (قبول filled / طلب تعديل tonal / رفض outlined بالخطأ)، الحقول على `.md3-field`، شارات الحالة بألوان الحاويات (`info/success/warning/error-container`)، زر الرجوع `md3-btn--text` بأيقونة، checkbox النشر 20px بهدف لمس 40px، ومعاينة الصورة بزاوية M3. |
| **الألوان الثابتة** | استُبدلت كل قيم `#hex` و`rgba(...)` الدلالية برموز M3 (بما فيها `STATUS_COLORS`، شارات الحالة، نصوص النجاح/الخطأ). لم يتبقَّ أي hex إلا قيم ألوان العلامة التجارية الافتراضية و`text-white` داخل معاينة الشعار الحية (خلفيتها لون يختاره المدير). |
| **الخطوط** | كل `text-[9..11px]` → `text-xs` (12px)، تسميات الحقول 12px → **14px**، وعناوين الأقسام 16px. |
| **`opacity` على النص** | أُزيل من بطاقة مزوّد AI ومن أزرار البحث/التحريك؛ الحالات المعطّلة تستخدم `disabled:` القياسي أو رمز لون بديل. |
| **تصحيح نصي** | أُصلح نص تالف قديم في قسم الشهادات («الحضور个人ي» → «الحضور الشخصي»، «شخصياً»). |
