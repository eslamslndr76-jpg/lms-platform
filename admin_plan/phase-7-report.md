# تقرير المرحلة 7: مراجعة الأخطاء

التاريخ: 2026-11-23. المراجعة بالوكلاء على ثلاثة محاور (الزمن، النظافة والأنواع، الصلاحيات) + إصلاح الحضور المؤكد. الجداول: الموضع | المشكلة | الخطورة | أُصلح؟

## أ) الإصلاح المؤكد: «الحضور المفتوح» — تم وتحقق بالاختبار

- **تعريف واحد**: `ATTENDANCE_OPEN_SQL` = `attendance_active=1 AND datetime(attendance_expires_at) > datetime('now')` — `datetime()` يوحّد الصيغتين المخزنتين فلا مقارنة نصية خام (`routes/attendance.ts`).
- **الكتابة بصيغة واحدة**: `/start` يكتب `attendance_expires_at = datetime('now','+2 hours')`.
- **التطبيق**: `/current` و`/mark` (رسالة «انتهى وقت تسجيل الحضور» + `expired:true`) و`/poll` (شرط الانتهاء في WHERE)، وقائمتا المحاضرات للطالب والأدمن (`getMyGroupLectures`/`getGroupLectures`) ترجعان `attendance_active` محسوباً من التعريف نفسه.
- **تنظيف كسول**: `closeExpiredSessions()` يطفئ الجلسات المنتهية عند القراءة (في /current و/mark و/poll).
- **الإغلاق عند الإتمام**: إتمام محاضرة (`toggleLectureComplete`) وإنهاء مجموعة (`completeGroup`) يغلقان جلسات الحضور المفتوحة.
- **الأدمن**: نافذة الحضور تعكس الواقع (انتهت) و`/start` يعيد الفتح بأي وقت.
- **الاختبار (11/11 PASS)**: فتح ← انتهاء ← `mark` مرفوض بالرسالة الصحيحة ← التنظيف الكسول يطفئ ← `/poll` لا يعرض ← قائمة الطالب صفر ← إعادة فتح ناجحة ← القائمة تُظهر مفتوحاً ← إتمام المحاضرة يغلق.
