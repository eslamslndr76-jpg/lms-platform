# تقرير المرحلة 10: الهيكل وتسجيل الدخول والرئيسية والحساب

التاريخ: 2026-11-23. تعديل مظهر فقط — المنطق لم يتغير.

## ما نُفذ
| الملف | التغيير |
|---|---|
| `app/ClientLayout.tsx` | حماية الصفحات ومنطق التوجيه كما هو تماماً؛ أُضيفت فقط حالة الدرج/الطي التي يملكها ويتلقاها `Sidebar` و`TopAppBar`، والمحتوى يزيح بهامش `--admin-sidebar-w` (ديسكتوب فقط). |
| `app/login/page.tsx` | بطاقة دخول M3: `surface-container-lowest` بزوايا extra-large وظل elevation-2، الشعار من الهوية، حقلان `md3-field` بتسميات مربوطة (`htmlFor`)، زر «إظهار/إخفاء» كزر text، رسالة الخطأ بحاوية `error-container` مع أيقونة، وزر دخول بحالة تحميل (spinner + نص). الوظيفة (`login`) كما هي. |
| `app/page.tsx` | لوحة رئيسية M3: تنبيهات بحاويات الحالة (`warning-container` للطلبات المعلقة والمجموعات الناقصة، `error-container` للطلاب غير المسكّنين)، بطاقات إحصاء بأيقونات Material Symbols وألوان رموز (success/warning/primary/tertiary)، جدول آخر الطلبات ببطاقة outlined. **أُضيفت حالات خطأ/تحميل/«تعذّر التحميل»** — سابقاً كان فشل الجلب يظهر كـ«صفر تنبيهات» (ملاحظة المرحلة 7). |
| `app/account/page.tsx` | قسمان على `surface-container-low`: الصورة الشخصية (زر كاميرا M3)، حقول `md3-field` بتسميات، ورسائل نجاح/خطأ بحاويات الحالة بدل `bg-green-50`؛ تلميح «6 أحرف على الأقل» للنص المساعد. |

## إزالة الألوان والأصناف الخام
- `login`: أُزيل `#dc2626`/`#fef2f2` و`var(--primary,#2563eb)` و`text-white`.
- `page.tsx`: أُزيلت كل hex (`#fef3c7 #f59e0b #92400e #b45309 #fef2f2 #991b1b #b91c1c #059669 #d97706 #2563eb #7c3aed`) و`animate-pulse` على التنبيه.
- `account`: أُزيلت `bg-green-50 dark:bg-green-900/30` و`bg-white dark:bg-gray-700` وربط `'var(--primary)' + '20'` غير الصالح.
- لا `text-[9..11px]` ولا `opacity` على النص في الملفات الثلاثة (المتبقي `text-[16..26px]` أحجام أيقونات Material Symbols فقط).

## التحقق
- `npm run typecheck`: نظيف للثلاثة.
- `ClientLayout`: فحص الصلاحيات (`SECTION_BY_PATH` + `canOpen`) وإعادة التوجيه لم يُمسّا.

`npm run dev:admin` ← `/login` و`/` و`/account` بعرض 360 و1280، فاتح وداكن. (المرحلة تتوقف هنا بانتظار المعاينة.)
