# تقرير المرحلة 12: صفحة الكورس والمجموعات (admin-ui)

التاريخ: 2026-11-23. الملف 3,035 سطراً — **تعديل مظهر فقط**، لم يُعَد هيكلته ولم يُقسم، ولم تتغير أي وظيفة.

## ما نُفذ
| العنصر | التغيير |
|---|---|
| **التبويبان** (تبويبات الكورس + تبويبات المجموعة داخل الحوار) | تحويل إلى تبويبات M3 الثانوية `.md3-tabs` / `.md3-tab` — مؤشر سفلي 3px بلون primary، تمرير أفقي على الموبايل، `role=tab` + `aria-selected`، وحالة نشطة واضحة بلا ألوان ثابتة. |
| **بطاقات الأقسام الأربعة** | `rounded-2xl + shadow-sm + border` → `.md3-card--outlined` بزوايا M3. |
| **الحقول** | 31 حجماً/نمطاً متكرراً لحقول الإدخال → `.md3-field` موحّد، و48 تسمية من 12px → 14px بلون `on-surface`. |
| **الألوان الثابتة** | استُبدلت **94 قيمة hex** برموز M3 دلالية: family الخطأ/النجاح/التحذير/المعلومة + الحاويات (`*-container` / `on-*-container`) + سطح/حدود/نص. |
| **الأزرار** | كل أزرار `rounded-xl py-3` صارت `md3-btn` بأنواعها: filled للفعل الرئيسي ونماذج الحفظ، outlined للثانوي، danger للحذف/الإيقاف، text لأفعال الصفوف. |
| **أفعال الصفوف** | إعادة فتح/إنهاء/تعديل/حذف (مجموعات)، تعديل/حذف (محاضرات)، نقل/إزالة (طلاب): أزرار `md3-btn--text` مع أيقونات Material Symbols بدل الإيموجي. |
| **نافذة الحضور (QR)** | لوحة QR على `#ffffff` **ثابتة حتى في الوضع الداكن** مع `fgColor=#000000` وحجم 260px وحدّ `outline-variant` — أقصى تباين للمسح. الكود اليدوي 36px بتباعد 0.4em على `surface-container-highest`. حالة الجلسة بأيقونة `sensors` + عدّ تنازلي 18px `tabular-nums`. بطاقات الملخص برموز `on-*-container`. قائمة الحضور: ✓/✗ أيقونات بدل الإيموجي و`opacity-70`. |
| **الحوارات** | كل الحوارات تستخدم `Modal` (M3) من المرحلة 9 تلقائياً؛ أزرارها الداخلية حُوّلت للأصناف الجديدة. |
| **النصوص الصغيرة** | 4 مواضع `text-[9..11px]` → `text-xs` (12px). |
| **التخفيت** | لا `opacity` على نص؛ موضع التمرير الأخير استُبدل بـ`.md3-state-layer`. |

## التحقق

- فحص الملف: 0 `#hex` (عدا `#ffffff`/`#000000` داخل لوحة QR — مقصودة)، 0 `text-[9..11px]`، 0 `bg-{amber,emerald,blue,red}-*`، 0 `bg-[var(...)]`، 0 `dark:` متبقٍ، 0 `opacity` على نص.
