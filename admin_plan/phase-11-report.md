# تقرير المرحلة 11: صفحات الإدارة (admin-ui)

التاريخ: 2026-11-23. تعديل مظهر فقط — لا حقل ولا زر ولا إجراء حُذف، والوظائف كما كانت.

## ما نُفذ صفحة بصفحة
| الصفحة | التغيير |
|---|---|
| `/financials` | Skeleton أثناء التحميل، خطأ بعنوان واضح وإعادة محاولة، ثلاث بطاقات إحصاء بأيقونات Material Symbols ورموز (primary/success/warning)، الجدول في `surface-container-low` بحالة شارة عبر `StatusBadge`، وحالة فارغ «لا توجد حركات مالية». |
| `/students/[id]` | أقسام كروت منظمة (رأس + بيانات شخصية + طلبات + مجموعات)، شبكة معلومات بحقول LTR للرقم القومي/التاريخ، حالة خطأ ظاهرة قبل التوجيه (كانت صامتة — بند من مرحلة 7)، أزرار تصدير M3. |
| `/students` | رأس وفعل رئيسي واحد (filled) + تصدير soft، تحويل كل الحقول إلى `md3-field`، أفعال الصف إلى أزرار text، الحالة بأيقونة نجاح/خطأ بدل الإيموجي، حوارا التعديل/الإضافة بحقول outlined وتسميات 14px، حوار التفاصيل بأزرار filled/danger. |
| `/courses` | نفس النمط: رأس بعنوان فرعي، عمود النوع/الحالة بأيقونات، أفعال الصف text، حقول `md3-field` بعد إزالة الأنماط المضمّنة المكرّرة، تحويل تخطيط الجدول إلى `section`. |
| `/orders` | رأس وفعل رئيسي، أزرار الحالة (موافقة/مراجعة/رفض) إلى filled/tonal/danger، حذف الكورس من الطلب بأيقونة error، حالات تحميل/خطأ قياسية. |
| `/certificates` | استبدال ~76 موضع لون/خط خام: شارات الحضور الثلاثية برموز نجاح/تحذير/خطأ، أشرطة النسبة برموز M3، الشرائح والصافي (chips/pills) بحاويات الحالة، النصوص 10-11px → `text-xs` (12px)، «ملغاة» بحدّ جانبي بدل `opacity-60` على البطاقة، مسح البحث بزر أيقونة. |
| `/proposals` | شارات الحالة برموز info/success/error/warning، شرائح الفلترة M3 (secondary-container للنشط)، بحث `md3-field`، زر تحديث outlined بأيقونة، حالة فارغ بأيقونة. |

## أدوات مساعدة أُضيفت إلى `globals.css`
`.msg-ok` / `.msg-err` (حاويات نجاح/خطأ للرسائل)، `.chip-active` (شريحة مفعّلة)، `.cert-revoked` (تمييز حدّي بدل تخفيت النص).

## التحقق
- `npm run typecheck`: **0 أخطاء** للثلاثة.
- فحص آلي لكل الصفحات السبعة: **0** `text-[9..11px]`، **0** `opacity-40/50/60`، **0** `bg-{gray,blue,red,green,amber,yellow}-{50,100,900}`، **0** `#hex`، **0** `bg-[var(...)]`.
- سكربت التباين: 40/40 زوجاً تجتاز.
