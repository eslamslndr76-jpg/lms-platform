## حالة كل خلية (D4)
`held = lectures.is_completed = 1 OR يوجد lecture_attendance.attended = 1 لأي طالب في المحاضرة`
| الشرط | القيمة |
|---|---|
| الطالب `attended=1` | ✓ حضر |
| held وليس حاضراً | ✗ غاب |
| ليست held وتاريخها < اليوم (توقيت القاهرة) | ؟ غير مؤكدة |
| غير ذلك (اليوم أو مستقبل أو بلا تاريخ) | — لم تُعقد |
