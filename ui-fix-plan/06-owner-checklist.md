# F1 المراجعة النهائية + قائمة تجربة المالك

## الوكيل (F1)
- [ ] `npm run typecheck` ينجح.
- [ ] مراجعة `git diff main...ui-excel-fixes`: لا تغييرات خارج النطاق، ولا تعديل في `flutter_app/` أو `user-ui/`.
- [ ] تحديث `api-contract.md` لو تغير سلوك التصدير.
- [ ] ملخص للمالك بالعربي: ماذا تغير وما الذي يحتاج تجربته. **لا دمج ولا نشر.**

## المالك (علّم بنفسك)
شغّل الفرع محلياً بالأمر `npm run dev` (اللوحة على المنفذ 3002).

### الواجهة (كمبيوتر)
- [ ] كل قسم يفتح ومحتواه ظاهر من أعلى بدون سكرول
- [ ] العنوان ظاهر كاملاً، والقايمة مفتوحة ومطوية
- [ ] القايمة المطوية: اللوجو والأيقونات كاملة
- [ ] النوافذ المنبثقة لا يغطيها شيء
- [ ] الجداول مرتبة وبدون سكرول أفقي
- [ ] صفحة تفاصيل الكورس ونافذة المجموعة
- [ ] الوضع الداكن
- [ ] نظرة سريعة على الموبايل: القايمة تفتح وتقفل

### الإكسل
- [ ] النزول عادي، لا شيء ثابت ولا رؤوس متكررة (**هذا يؤكد أو ينفي سبب X2**)
- [ ] اللوجوهين كبار وواضحين وغير مشوهين
- [ ] طالب واحد = صف واحد
- [ ] محاضرة مستقبلية تظهر «—» ولا تحسب غياباً
- [ ] وقت الحضور مطابق لتوقيت القاهرة
- [ ] معاينة الطباعة: صفحة عرضية مظبوطة والتوقيعات ظاهرة
- [ ] جرب تقرير الطلاب والطلبات أيضاً
- [ ] جرب على البرنامج الذي ظهر فيه التكرار أول مرة

لو أي بند فشل: رجّع مهمته في `PROGRESS.md` إلى `[ ]` واكتب السبب مع صورة.
