## للوكيل: بروتوكول العمل (إلزامي)
1. اقرأ بالترتيب: هذا الملف ← `PROGRESS.md` ← `01-diagnosis.md` ← ملف مرحلتك فقط.
2. هذه الخطة هي خطة العمل الحالية. قواعد `AGENTS.md` سارية.
3. اعمل على الفرع `ui-excel-fixes` فقط. **ممنوع** الدمج في `main` أو النشر.
4. اختر أول مهمة حالتها `[ ]` وكل ما تعتمد عليه `[x]`.
5. **احجز المهمة قبل أي تعديل:** غيّرها إلى `[~]` مع اسمك ووقت البدء، ثم commit وpush لملف `PROGRESS.md` وحده. لو رُفض الـpush: اعمل `git pull --rebase`، ولو المهمة اتحجزت اختر غيرها.
6. مهمة `[~]` لوكيل آخر لا تلمسها إلا بإذن المالك. لو أنت تكمل مهمة متوقفة بإذنه، اقرأ ملاحظاتها أولاً.
7. لا يعمل وكيلان على نفس الملف. المسار A (واجهة) والمسار B (باك إند) يعملان بالتوازي، وداخل كل مسار بالترتيب.
8. **الفحص:** `npm run typecheck` فقط (و lint للملفات المعدلة عند الحاجة). ممنوع المتصفح وPlaywright والـbuild.
9. عند الانتهاء: `[x]` مع التاريخ والوقت، ثم commit للمرحلة وpush للفرع.
10. الوقت يؤخذ من النظام ولا يُخمَّن: `TZ=Africa/Cairo date '+%F %H:%M'`
11. لو توقفت قبل الإنهاء: اكتب في «سجل التسليم» ماذا تم وماذا بقي. لو فيه مانع: `[!]` مع السبب.
12. `[x]` تعني «الكود اتكتب وtypecheck نجح». لا تعني أن الشكل اتأكد؛ هذا يؤكده المالك في العمود المخصص.
