# المسار A — التخطيط العام (L1–L3)

## L1 القايمة والشريط العلوي والمحتوى (U1, U2, U3)
الملفات: `Sidebar.tsx`, `TopAppBar.tsx`, `ClientLayout.tsx`, `app/globals.css`
- [ ] `<aside>`: تبقى `fixed top-0 right-0 h-screen` في كل المقاسات؛ احذف `lg:sticky lg:top-0 lg:h-screen`، وأبقِ `lg:translate-x-0`.
- [ ] أضف في `globals.css`: `.admin-topbar{right:0}` وعند `min-width:1024px`: `.admin-topbar{right:var(--admin-sidebar-w,280px)}`. استخدمها في الشريط العلوي بدل `right-0`.
- [ ] `<main>`: استبدل `pt-16 p-4 lg:p-6` بـ `px-4 pt-20 pb-24 lg:px-6 lg:pt-[88px]`.
- [ ] انتقال العرض عند الطي متزامن للقايمة والشريط والمحتوى (نفس المدة 300ms).

**القبول:** أول المحتوى ظاهر بدون سكرول في كل الأقسام؛ العنوان كامل بجانب القايمة مفتوحة ومطوية.

## L2 القايمة المطوية (U4, D9)
- [ ] على الكمبيوتر وهي مطوية: رأس القايمة عمودي (اللوجو فوق، زر التوسيع تحته)، اللوجو `h-9 w-auto max-w-[60px] object-contain`.
- [ ] الأقسام أيقونات فقط بمقاس موحد 48×48، ومنها «حسابي» و«تسجيل خروج»، مع `title` و`aria-label`.
- [ ] لا سكرول أفقي داخل القايمة.
- [ ] درج الموبايل يعرض الأسماء دائماً حتى لو `collapsed=true`.
- [ ] اتجاه السهم صحيح في RTL (يشير لليمين للطي، ولليسار للتوسيع).

**القبول:** اللوجو وكل الأيقونات كاملة وفي المنتصف.

## L3 الأزرار العائمة والطبقات (U5, U6, U7)
- [ ] زرار المساعد الذكي ونافذته: `z-[45]`، ويبقى `Modal` عند `z-50`. تأكد أنه لا يظهر فوق `ConfirmDialog`.
- [ ] احذف زر القائمة العائم على الموبايل.
- [ ] خلفية درج الموبايل `z-[35]`.
- [ ] راجع موضع `Toast` و`NotificationBell` حتى لا يغطي أحدهما الآخر.

**القبول:** لا شيء عائم فوق أي نافذة منبثقة ما عدا التنبيهات (Toast).
